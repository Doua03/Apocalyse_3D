# The Last One — 3D Post-Apocalyptic Environment

## Overview

**The Last One** is an academic 3D environment project developed using Unity and Blender. The project consists of a post-apocalyptic city inhabited by zombies, featuring abandoned buildings, vegetation, environmental props, and animated characters.

Developed as part of a team of two, the project explores 3D modeling, asset integration, animation, lighting, and cinematic scene design.

## Features

- **3D Environment:** A post-apocalyptic city featuring buildings, trees, barriers, vegetation, and environmental props.
- **3D Modeling:** Custom modeling of a car and a streetlight using Blender, followed by integration into Unity.
- **Asset Integration:** Integration of buildings from Sketchfab, environmental assets from the Unity Asset Store, and a zombie character from Mixamo.
- **Materials and Textures:** Application of building textures and colored materials to custom 3D models.
- **Zombie Animation:** Character movement implemented using Unity's Animator and C# scripting.
- **Lighting and Shadows:** Directional lights, point lights, and spotlights configured to create atmosphere and soft shadows.
- **Interactive Lighting:** A C# script controlling the random flickering of a streetlight.
- **Cinematic Sequence:** An aerial flyover of the environment created using Unity's Animation window.

## Technologies Used

- **Unity** — 3D environment development and scene composition.
- **C#** — Animation control and environmental behavior.
- **Blender** — 3D modeling.
- **Mixamo** — Zombie character and animation resources.
- **Sketchfab** — 3D building assets.
- **Unity Asset Store** — Environmental assets.

## Getting Started

1. Clone or download this repository.
2. Open Unity Hub.
3. Select **Add Project from Disk** and choose the project folder.
4. Open the project using a compatible Unity Editor version.
5. Open the main scene from the `Assets/Scenes` folder.
6. Press **Play** to explore the environment and view its animations.
